دعوة عيد ميلاد مينا فؤاد مرقص — GitHub Pages

الملفات:
- index.html: الصفحة الأولى والتفاصيل في نفس الموقع.
- style.css: التصميم والألوان.
- script.js: فتح الدعوة، ظهور الصورة الكرتونية لمدة 2.2 ثانية، ثم الانتقال للتفاصيل والأزرار.
- mina-cartoon.jpg: الصورة الكرتونية التي تظهر بعد الضغط على «افتح الدعوة».

رفع الموقع:
1. فكّي ضغط ZIP.
2. ارفعي الملفات الأربعة مباشرة إلى جذر مستودع GitHub، وليس ملف ZIP نفسه.
3. تأكدي أن index.html وstyle.css وscript.js وmina-cartoon.jpg بجانب بعضهم مباشرة.
4. من Settings > Pages اختاري Deploy from a branch ثم main و/(root) ثم Save.

ملاحظات:
- التاريخ والوقت والمكان بيانات افتراضية ويمكن تغييرها داخل index.html وscript.js.
- زر اللوكيشن يفتح بحث Google Maps عن قاعة جرين لاند بمدينة نصر.
- زر تأكيد الحضور يجهز رسالة قابلة للمشاركة ولا يحفظها تلقائياً في جدول.
- زر صور الحفلة يعرض رسالة مؤقتة إلى أن تضيفي رابط ألبوم الصور.
- صورة مينا لا تظهر على الغلاف الأول؛ تظهر وحدها بعد الضغط على فتح الدعوة ثم تختفي وتظهر صفحة التفاصيل.

- birthday-song.mp3: الأغنية المرفوعة؛ تبدأ عند فتح الصفحة الثانية وتستمر بالتكرار، وتتوقف عند الرجوع للغلاف. بعض المتصفحات قد تمنع التشغيل التلقائي؛ الضغط على زر فتح الدعوة يسمح ببدء الصوت عادةً.
